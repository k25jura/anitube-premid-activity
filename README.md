# AniTube.in.ua - PreMiD Presence

PreMiD Discord Rich Presence activity for [AniTube.in.ua](https://anitube.in.ua/), a Ukrainian anime portal.
Активність PreMiD у Discord Rich Presence для [AniTube.in.ua](https://anitube.in.ua/) — українського порталу про аніме.



## English

### Features
- Video playback tracking with live timeline slider (elapsed and remaining time)
- Pause indicator with paused state preservation
- Season and episode display (e.g., Season 3 • Episode 5, Movie, OVA)
- Anime poster cover display
- User lists and bookmarks tracking (All Anime, Completed, Plan to Watch, Watching, On-Hold, Dropped, Favorites)
- Comprehensive site support (Watchrooms, Seasons, Top Anime, AnimeTube, Kawai Chat, Direct Messages, Statistics, News, Articles, and Categories)
- Privacy mode support
- Built-in language switcher (Ukrainian / English)

### Installation & Development
1. Clone the repository or download the source files.
2. Install the [PreMiD browser extension](https://premid.app/).
3. Enable **Activity Developer Mode** in the PreMiD extension settings.
4. Load the activity directory through the PreMiD developer tab or run via the PreMiD CLI:
   ```bash
   npx pmd dev "AniTube.in.ua"
   ```

## Українська

### Можливості
- Відстеження відтворення відео з інтерактивним повзунком часу в Discord
- Відображення стану паузи з фіксацією поточного часу
- Відображення сезону та номера серії (наприклад, 3 сезон • 5 серія, Фільм, OVA)
- Показ постера аніме
- Відстеження списків користувача (Всі аніме, Переглянуто, Заплановано, Переглядаю, Відкладено, Покинуто, Улюблене)
- Підтримка всіх розділів сайту (Кімнати спільного перегляду, Сезони, Топ аніме, AnimeTube, Кавайний чат, Особисті повідомлення, Статистика, Новини, Статті, Каталог)
- Підтримка режиму приватності
- Вбудований перемикач мови (Українська / English)

### Встановлення та розробка
1. Склонуйте репозиторій або завантажте файли.
2. Встановіть розширення [PreMiD](https://premid.app/).
3. Увімкніть **Параметри розробника** у налаштуваннях розширення PreMiD.
4. Завантажте папку активності через параметри розробника або запустіть через PreMiD CLI:
   ```bash
   npx pmd dev "AniTube.in.ua"
   ```
